# 面向红外车内人头漏检的目标检测方法综述

## 1. 范围与问题定义

本综述关注单类别红外人头检测，目标位于运动中的车辆侧窗内，具有目标小、相邻、遮挡、玻璃反光、亮度剧变和连续帧相关性强等特点。检索重点不是所有“YOLOv8 改进论文”，而是能够解释并解决以下瓶颈的可迁移方法：

1. 小目标在下采样后缺乏有效特征和正样本。
2. 相邻人头可能在 NMS 或标签分配中互相竞争。
3. 遮挡与形变使固定卷积采样不理想。
4. 检测分数与定位质量不一致。
5. 跟踪入口过高阈值丢弃了可用于续轨的真阳性。

## 2. 主题一：先放大目标，再改网络

SAHI 通过切片推理和切片微调提高小目标检测，原论文在 VisDrone/xView 的多种检测器上报告了显著 AP 增益。它最重要的启示不是必须全图切片，而是让目标在网络输入中占据更多像素。本项目具有更强的车辆位置先验，因此“车辆或车窗 ROI 裁剪后检测”应优先于通用 SAHI：计算更少、背景干扰更小、重复框融合更简单。

TPH-YOLOv5 在 VisDrone 场景增加高分辨率预测头，并用 Transformer prediction head 增强小目标表达。这支持本项目测试 P2/stride-4 检测头，但不等于必须复制整套 Transformer head。当前目标缩放到 640 后第 10 分位约 12×15 px，增加 P2 有明确数据依据。

NWD 指出 IoU 对极小框的少量像素偏移过于敏感，并提出更平滑的距离与分配策略。它与本项目 mAP50 高、mAP50-95 明显偏低的现象相关。但 NWD 的原始证据来自航空极小目标；只有当 `<16 px` 分组确实主导误差时才值得侵入标签分配和回归代码。

## 3. 主题二：多尺度融合比随意堆注意力更直接

EfficientDet 的 BiFPN 使用可学习权重进行双向跨尺度融合，是成熟且广泛复用的多尺度设计。对本项目而言，它比在 backbone 中到处加注意力更容易形成可解释消融：如果小目标与遮挡组提升，而大目标不退化，说明跨尺度融合有效。

CBAM 是经典通道—空间注意力模块，Coordinate Attention 则把位置信息嵌入通道注意力，对轻量网络和检测任务更友好。两者都是“可测试组件”，而不是必然涨点。由于 YOLO neck 已包含多尺度融合，建议只在高分辨率分支或 neck 后段插入一个模块，Coordinate Attention 优先于 CBAM，并与无注意力基线严格比较。

YOLOv12 的 Area Attention 说明注意力可以在实时 YOLO 中以更系统的架构方式使用。若想验证全局上下文是否帮助车窗遮挡，直接训练标准 YOLO12m 比自行拼装多个注意力块更容易维护和归因。

## 4. 主题三：可变形卷积适合遮挡与形变，但工程风险较高

DCNv4 通过动态、稀疏采样增强几何适应性并改进实现效率。车窗透视、乘员姿态和部分遮挡是它可能有效的原因。风险在于其自定义算子、Windows 编译、ONNX/TensorRT 导出和部署兼容性；因此只建议在最佳标准模型的一个融合块做单点替换，不应作为首轮方案。

## 5. 主题四：置信度应代表质量，而不是只做类别判断

Generalized Focal Loss 将分类质量与定位质量统一建模，并用 Distribution Focal Loss 表达边界分布；YOLOv8 已经吸收了 DFL 思路。VarifocalNet 进一步学习 IoU-aware classification score，使候选框排序同时考虑目标存在和定位质量。这些工作解释了为什么“提高分类置信度”不等于“提高 AP50-95”。

本项目不应第一轮重写 GFL/VFL，因为当前最大的确定性问题是入口阈值 0.6、没有负图和输入目标过小。若修复这些问题后仍出现高分但定位差，再比较 IoU-aware scoring 或其他质量分支。

## 6. 主题五：替换整机模型往往比拼模块更可靠

RT-DETR 以实时端到端 DETR 消除 NMS，适合检验相邻人头是否被 NMS 抑制。其优势来自完整的 encoder、query selection 和训练设计，不能简化为“Transformer 一定更强”。对密集小目标，稀疏匹配也可能训练不足，所以应作为对照模型而非默认替代。

YOLOv10 用 consistent dual assignments 推进 NMS-free YOLO；YOLO12系统化引入 Area Attention；YOLO26进一步使用双头端到端推理、STAL 小目标标签分配和更新的训练配方。当前仓库已经原生支持 YOLO26，且 STAL 与小目标漏检直接相关，因此 YOLO26m 是比“YOLOv8s+多个自定义模块”更优先的候选。

## 7. 对本项目的证据排序

### 高优先级

1. 车辆 ROI 或 SAHI 思路：直接增加人头有效像素。
2. 低阈值候选加高低分二阶段跟踪：直接解决 `conf=0.6` 丢弃真阳性。
3. P2 检测头或 YOLO26 STAL：直接针对小目标正样本和高分辨率特征。
4. `s -> m` 加 960 输入：最简单、可复现的容量与分辨率升级。
5. 难负样本挖掘：解决反光和头枕误检，支撑降低阈值。

### 中优先级

1. BiFPN。
2. Coordinate Attention。
3. RT-DETR NMS-free 对照。
4. YOLO12m 标准模型对照。

### 低优先级或条件性方法

1. CBAM：只作为注意力基线。
2. DCNv4：仅在部署算子兼容时。
3. NWD/RKA：仅在极小目标定位与分配仍是瓶颈时。
4. 重写 GFL/VFL：当前不具备最高收益/复杂度比。
5. YOLOv8x：在 m/l 尚未证明容量受限前不做。

## 8. 证据局限

- 多数基础论文在 COCO、VisDrone、xView 或航空数据上评估，不能直接外推到红外车内人头。
- 应用型“改进 YOLOv8”论文常把多个模块一起加入、只报单数据集单次结果，难以区分真实贡献和训练随机性。
- 论文中的 AP 增益不是本项目的预期涨幅；本项目必须用按车辆隔离的独立测试集验证。
- YOLO26 很新，尚不属于高被引工作；将其纳入是因为方法与本问题高度匹配且当前代码库原生支持，而不是因为引用量。
