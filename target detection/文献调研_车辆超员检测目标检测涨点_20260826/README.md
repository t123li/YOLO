# 车辆超员检测：目标检测涨点资料包

生成日期：2026-08-26

本资料包针对红外道路侧视车辆超员场景中的车内人头漏检问题。它不是一份“堆模块清单”，而是一套从数据审计、阈值与输入、模型尺度、结构消融到跟踪和计数验收的可执行方案。

## 文件导航

- `目标检测涨点计划.md`：建议直接从这里开始，包含诊断、实验矩阵、训练命令模板、晋级标准和时间安排。
- `文献综述.md`：按问题主题整理文献证据，并说明哪些方法适合本项目、哪些不建议优先做。
- `论文证据表.csv`：论文、方法、证据强度、项目相关性和建议优先级。
- `检索记录.md`：数据库、检索式、纳入排除标准及检索限制，便于复现。
- `references.bib`：可直接用于论文写作的 BibTeX 条目。
- `PDFs/`：13 篇开放获取论文全文。
- `figures/实验决策流程.png`：本项目实验决策图。

## 一句话结论

第一轮不要直接魔改 YOLOv8，也不要首先上 YOLOv8x。先修正跟踪入口的 `conf=0.6`、加入低分框二阶段关联、以车辆 ROI 放大人头、补充纯背景和反光难负样本，并冻结按车辆/序列划分的测试集。随后在同一协议下比较 `YOLOv8m@960`、`YOLO26m@960` 和一个 P2 小目标头版本；只有最优基线仍在小目标或遮挡组显著漏检时，再逐个消融 BiFPN、Coordinate Attention 或 DCNv4。

## 重要限制

- 当前只能读取已有训练产物，未在本机重新运行 `best.pt` 验证，因为当前 Python 环境未安装 PyTorch。
- 当前指标来自已有验证记录，而非独立、按车辆隔离的新测试集。
- OpenAlex 当日公共额度耗尽，Semantic Scholar 公共池返回 429，因此没有把动态引用次数写成硬指标；“高被引/基础工作”的筛选依据为成熟度、顶会/期刊、后续复用广度及可核验的主论文。
- `scientific-schematics` 所需 OpenRouter 密钥未配置，流程图改由内置图像生成工具生成并人工核对；源图中 `YOLOv8-m/l` 的小写字母 `l` 在字体上可能近似大写 `I`，不影响含义。
